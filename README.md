# 🎮 GPU Comparison

**Сервис для сравнения производительности видеокарт в популярных играх для геймеров.** Помогает выбрать оптимальную видеокарту по критериям FPS, цены и эффективности (FPS/1000 рублей).

## ✨ Основные возможности

- **📊 Сравнение производительности**: Топ-5 видеокарт по разным критериям:
  - Максимальный FPS
  - Лучшая эффективность (FPS/1000 рублей)
  - Оптимальные бюджетные варианты
- **🎯 Интерактивные графики**: Визуализация результатов с помощью Plotly
- **🔍 Умный поиск**: Проверка наличия тестов производительности перед сравнением
- **📱 Адаптивный дизайн**: Работает на любых устройствах

## 🚀 Быстрый старт

###
```bash
# Клонировать репозиторий
git clone https://github.com/LanikTop/GPUCompare.git
cd GPUCompare
# Создание виртуального окружения
python -m venv venv

# Активация для Windows:
# PowerShell: venv\Scripts\Activate.ps1
# CMD: venv\Scripts\activate.bat
# macOS/Linux: source venv/bin/activate

# Установка пакетов
pip install -r requirements.txt

# Применение миграций
python manage.py migrate

# Загрузка тестовых данных
python manage.py loaddata core/fixtures/initial_data.json

# Создать суперпользователя (по желанию)
python manage.py createsuperuser

# Запустить сервер
python manage.py runserver

#Перейдите по адресу: http://127.0.0.1:8000/
```

# 🎮 Использование
**Сравнение видеокарт**
1. Выберите параметры на странице сравнения:
    - Игру
    - Разрешение экрана
    - Настройки графики 
    - Минимальный FPS
2. Получите результаты:
   - Топ-5 по производительности (FPS)
   - Топ-5 по эффективности (FPS/1000 рублей)
   - Топ-5 бюджетных вариантов

3. Анализируйте графики:
   - Интерактивные графики с детальной информацией
